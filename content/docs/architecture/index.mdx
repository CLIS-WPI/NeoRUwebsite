## Two processes, one boundary

NeoRU separates work that must meet a deadline from work that need not. The **control process**, written in Rust, handles configuration and lifecycle. The **real-time data plane** does the slot-timed processing. The two meet at exactly one point, the **configuration hand-off**, which is the only lock-free component in the design.

Keeping that boundary single and small is what makes it possible to check it carefully.
