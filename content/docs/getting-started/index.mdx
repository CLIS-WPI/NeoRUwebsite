## Repository & Release Status

NeoRU is developed in the **CLIS Lab** (Department of Electrical and Computer Engineering, Worcester Polytechnic Institute) and licensed under **Apache 2.0**.

- **Project repository:** [CLIS-WPI/NeoRU on GitHub](https://github.com/CLIS-WPI/NeoRU/)
- **Current status:** Public code release is pending. Detailed build guides, configuration references, and interface contracts will be published here as components are released.

## Completed Foundations

The following foundational milestones are complete as of **23 November 2026**:

1. **Architecture RFC** — Core architecture, ISAC and virtual-radio extensions, and the development plan.
2. **Development Environment & CI Gates** — Isolated environment with unit tests, ASan, UBSan, TSan, and emulated AArch64 builds.
3. **Seven Interface Specifications** — Written before implementation to establish clear contracts.
4. **Reference Measurement Baseline** — Measurement method and initial baseline for the reference O-RU (`ProtO-RU`).
5. **BFP Compression Codec** — Verified against the O-RAN CUS-plane specification and real DU traffic.
6. **Deterministic Virtual Radio** — Enables bit-exact O-RU testing without radio hardware.

## Adding Documentation Pages

This documentation site is powered by **Fumadocs**. New pages can be added directly as Markdown or MDX files under `content/docs/`:

```text
content/docs/
├── meta.json
├── index.mdx
├── getting-started/
│   ├── meta.json
│   └── index.mdx
├── architecture/
│   ├── meta.json
│   ├── index.mdx
│   ├── timing-and-core.mdx
│   └── virtual-radio.mdx
└── engineering/
    ├── meta.json
    ├── index.mdx
    └── benchmarks.mdx
```

Each folder uses a `meta.json` file to control sidebar ordering and section titles.
