## The goal

NeoRU aims to run one **20 MHz, 2×2** carrier of O-RAN split 7.2x on about **one CPU core**. That is a target, not a result. NeoRU has not yet been measured end to end, and any comparison will be made under the same conditions as the [reference baseline](/NeoRUwebsite/docs/engineering/benchmarks/).
