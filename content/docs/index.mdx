## Project goal

NeoRU targets running one **20 MHz, 2×2** O-RAN split 7.2x carrier on approximately **one CPU core**. This is an engineering target — end-to-end NeoRU measurement is still ahead, and any future comparison will be reported under the exact same test conditions as the reference baseline.
