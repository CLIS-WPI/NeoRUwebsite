## Reading the baseline

CPU use is the median number of CPU cores used by the reference O-RU. Package power is measured above idle and covers the **O-RU and DU together**. It is not an isolated radio-unit power figure, and it should not be compared with NeoRU's one-core goal.

## Rules for comparison

1. NeoRU is measured under the same conditions as the reference: carrier, MIMO, subcarrier spacing, traffic, CPU and core configuration.
2. Every result is published with its test configuration, measurement method and scope.
3. Each figure is labelled as a reference baseline, a preliminary run or a NeoRU result.
4. No speedup or efficiency ratio is stated until both sides have been measured this way.
